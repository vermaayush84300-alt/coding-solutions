## Problem

### Positive and Negative

Write a program to check whether a number given as user input is positive, negative, or zero.

### Sample 1:
Input
Output

```
20
```

```
Positive
```

### Sample 2:
Input
Output

```
0
```

```
Zero
```

### Sample 3:
Input
Output

```
-95
```

```
Negative
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-20T14:13:07.210Z  

```py
# cook your dish here
num = int(input());
if num>0:
    print("positive")
elif num<0:
    print("negative")
else:
    print("zero")
```
